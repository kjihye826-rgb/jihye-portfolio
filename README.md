# Jihye Kim Portfolio

김지혜의 영상·기획·디자인 경험을 담은 6개 Track 포트폴리오.

## 파일 구성

- `index.html`: 포트폴리오 첫 페이지
- `assets/`: 페이지에 필요한 이미지 원본
- `.nojekyll`: 정적 파일 제공용 설정
- `.gitignore`: 개인 설정 및 비밀키 파일 제외

## 사용 방법

`index.html`과 `assets` 폴더를 같은 위치에 유지하세요. `index.html`을 브라우저에서 열면 확인할 수 있습니다.

GitHub 저장소에는 ZIP 자체가 아닌, 압축을 푼 이 폴더 안의 파일과 `assets` 폴더를 올리세요. `index.html`이 저장소 최상위에 오도록 구성하세요.

별도의 설치, 빌드 명령 또는 API 키가 필요하지 않은 정적 웹사이트입니다. GitHub에 파일을 업로드하는 것과 웹사이트 공개 배포는 별도 작업입니다. 이 패키지는 업로드·배포를 실행하지 않습니다.

영상 썸네일 일부와 영상·Notion·Instagram 등의 외부 링크는 인터넷 연결 및 해당 서비스의 공개 상태에 따라 표시됩니다.

첫 표지는 `assets/portfolio_video.mp4` 영상입니다. 무음 자동 반복 재생과 수동 재생·일시정지 기능을 지원합니다. 브라우저가 자동 재생을 제한하면 재생 버튼을 눌러주세요. 영상 파일도 이미지와 함께 업로드해야 합니다.
